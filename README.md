## So starten wir

Für eine erste Einschätzung reichen diese fünf Angaben:

1. Welches konkrete Problem soll gelöst werden?
2. Wer nutzt die Website oder Anwendung?
3. Welche drei Funktionen sind zuerst wichtig?
4. Welche bestehenden Systeme müssen berücksichtigt werden?
5. Welcher Budgetrahmen und Zieltermin sind vorgesehen?

Danach klären wir Umfang, Zugang, Meilensteine, Verfügbarkeit und Vergütung vor Projektstart. Wartung und Betreuung werden separat abgegrenzt.
